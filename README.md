# Superstore Sales Analysis

An end-to-end data analysis project using Python, SQL and Statistics.

## What this project covers
- Loading data into SQLite and querying with SQL
- Data cleaning and exploration with Pandas
- Statistical analysis (mean, median, correlation, outliers)
- Data visualizations with Matplotlib and Seaborn

## Key Findings
- High discounts negatively impact profit
- Tables and Bookcases are loss-making sub-categories
- Sales peak in Q4 (November - December)

## Tools
Python | Pandas | SQLite | Matplotlib | Seaborn | Jupyter Notebook

## Dataset
[Sample Superstore - Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
